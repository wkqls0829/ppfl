## 프로젝트 목표
Variational Preference Learning (VPL) 및 Variational Preference Learning with Gumbel Softmax Prior (VPL-GP)을 활용한 Federated Reinforcement Learning from Human Feedback (RLHF) 시스템을 구현하고 있습니다.

## 주요 작업 내용

### 1. VPL (Variational Preference Learning)
- **클라이언트별 personalized preference learning**: 각 클라이언트마다 latent vector `z`를 추론하여 개인화된 preference 학습
- **Conditional DPO training**: 클라이언트별 `z`를 조건부로 사용하는 Direct Preference Optimization (DPO) 학습
- **Conditional data generation**: 각 클라이언트의 `z`를 embedding에 주입하여 conditional data generation
- **Personalized test evaluation**: 클라이언트별 test set으로 개인화된 성능 평가

### 2. VPL-GP (Variational Preference Learning with Gumbel Softmax Prior) ⭐ NEW
- **Gumbel Softmax Prior**: 다른 클라이언트들의 z-distribution을 mixture prior로 사용
- **Federated Prior Update**: 서버에서 클라이언트들의 z-distribution (mu, logvar)을 수집하고 브로드캐스트
- **KL Divergence with Mixture Prior**: 표준 정규분포 대신 다른 클라이언트들의 분포를 prior로 사용하는 KL divergence 계산
- **Binary Selector (HHST) 및 RL (HRL) 지원**: VPL-GP는 VPLRewardChoiceTrainer를 상속하여 binary selector와 RL 모두 지원

### 3. Preference feature difference + 서버 라벨 orthogonal loss ⭐ NEW
- **Feature difference 적용**: `(prompt + chosen) - (prompt + rejected)`로 z posterior 입력 생성
- **Choice 프롬프트 파싱**: `### RESPONSE A/B` 구간을 찾아 A/B 세그먼트 difference 계산
- **서버 라벨 기반 orthogonal loss**: 서버가 balanced k-means로 생성한 라벨을 orthogonal loss 정렬에 사용

## 최근 구현된 주요 기능

### 1. VPL-GP 알고리즘 구현 ⭐ NEW

#### VariationalEncoderGP (`federatedscope/llm/model/variational_encoder_gp.py`)
- **Gumbel Softmax Prior**: 다른 클라이언트들의 z-distribution을 mixture prior로 사용
- **Prior Update**: `update_prior()` 메서드로 서버로부터 받은 다른 클라이언트들의 z-distribution 업데이트
- **KL Divergence with Mixture**: `kl_divergence()` 메서드에서 mixture prior와의 KL divergence 계산
- **Gumbel Softmax Sampling**: `sample_prior()` 메서드에서 Gumbel Softmax를 사용한 differentiable sampling

#### VPLGPRewardChoiceTrainer (`federatedscope/llm/trainer/vpl_gp_reward_choice_trainer.py`)
- **VPLRewardChoiceTrainer 상속**: VPL의 모든 기능을 상속받으면서 Gumbel Softmax prior 추가
- **Z-distribution 수집**: 각 라운드에서 클라이언트의 z-distribution (mu, logvar) 수집
- **Prior 업데이트**: `update_prior_from_server()` 메서드로 서버로부터 받은 prior 업데이트
- **t-SNE 시각화**: VPL과 동일하게 z-history를 수집하여 t-SNE 시각화 (10라운드마다)

### 2. Server/Client 통신 메커니즘 ⭐ NEW

#### Server (`federatedscope/llm/llm_local/server.py`)
- **Z-distribution 수집**: `_perform_federated_aggregation()`에서 클라이언트들로부터 `client_z_mu`, `client_z_logvar` 수집
- **Prior 집계**: 수집된 z-distribution들을 `self.vpl_gp_prior_mus`, `self.vpl_gp_prior_logvars`, `self.vpl_gp_prior_weights`에 저장
- **Prior 브로드캐스트**: `broadcast_model_para()`에서 클라이언트들에게 prior 분포 브로드캐스트
- **Adapter filtering 버그 수정**: `callback_funcs_for_grouping()`에서 `self.msg_buffer['adapter_eval']` 초기화 추가
- **Balanced 라벨 생성/브로드캐스트**: z-mean 기반 balanced k-means로 `vpl_orthogonal_client_labels` 생성 및 전송

#### Client (`federatedscope/llm/llm_local/client.py`)
- **Z-distribution 전송**: `callback_funcs_for_model_para()`에서 `get_client_z_distribution()`으로 z-distribution을 `model_para_all`에 추가하여 서버로 전송
- **Prior 수신 및 업데이트**: 서버로부터 받은 `vpl_gp_prior_mus`, `vpl_gp_prior_logvars`, `vpl_gp_prior_weights`를 trainer의 `update_prior_from_server()`로 전달
- **Adapter filtering 우회**: z-distribution을 adapter filtering 이후에 추가하여 필터링되지 않도록 보장
- **Orthogonal 라벨 수신**: 서버 라벨을 `update_orthogonal_label_from_server()`로 전달

## 주요 클래스 및 메서드

### VariationalEncoderGP
- `encode(x)`: Input preference features를 latent parameters (mu, logvar)로 인코딩
- `reparameterize(mu, logvar)`: Reparameterization trick으로 z 샘플링
- `update_prior(client_mus, client_logvars, client_weights)`: 다른 클라이언트들의 z-distribution으로 prior 업데이트
- `sample_prior(batch_size, use_gumbel)`: Gumbel Softmax를 사용한 prior 샘플링
- `kl_divergence(mu, logvar, use_gumbel_prior)`: Mixture prior와의 KL divergence 계산

### VPLGPRewardChoiceTrainer
- `_hook_on_batch_forward(ctx)`: Forward pass에서 z 추론 및 KL divergence 계산
- `_hook_on_fit_end(ctx)`: 라운드 종료 시 z-history 수집 및 t-SNE 시각화
- `get_client_z_distribution()`: 클라이언트의 z-distribution (mu, logvar) 반환
- `update_prior_from_server(client_mus, client_logvars, client_weights)`: 서버로부터 받은 prior 업데이트
